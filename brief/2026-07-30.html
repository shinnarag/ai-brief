01

ARC-AGI-3 — retained reasoning + compaction으로 점수 약 3배·출력 토큰 6분의 1

  • (사실) 7/29 OpenAI 연구: GPT-5.6 Sol이 ARC-AGI-3(지시 없이 낯선 2D 퍼즐 게임을 학습하는 벤치)에서 초반 저점수(솔 7.8%, 5.5는 0.4%)로 의문이 생겼고, 공식 하네스 설정이 원인으로 드러남.
  • (원인) 매 액션 후 private reasoning 폐기 → 매 턴 게임을 처음부터 재해석. 컨텍스트 175k 문자 초과 시 롤링 truncation으로 과거 액션까지 소실. 모델 지능 한계가 아니라 기억 단절 하네스.
  • (수치) Responses API + retained reasoning + compaction으로 공개 세트 점수 13.3% → 38.3%(RHAE, 인간 평균 추정 ~48%). 출력 토큰 약 6배 감소. 한 게임 예시에서 공식 하네스는 1레벨 이상 못 깨고, 개선 하네스는 6레벨 전부 클리어.
  • (권고) 실서비스와 맞추려면 Chat Completions 대신 Responses API, reasoning 유지, compaction 사용. “벤치는 모델만이 아니라 API 설정·하네스·프롬프트 묶음” 메시지가 핵심.
  • (영향) 에이전트 평가·리더보드 비교 시 reasoning drop 여부를 스펙에 명시해야 하고, 제품 팀은 장기 에이전트 루프의 컨텍스트 정책(append-only·compaction)을 기본값으로 재검토할 시점.
