  • (가격) Gemini Enterprise Platform 표는 실시간이 오디오 입력 $3.50/1M·글 출력 $21/1M(대략 오디오 1분에 $0.009), 파일이 입력 $2.50/1M·출력 $12/1M(대략 오디오 1분에 $0.005)이에요. 이 분은 오디오 초당 25토큰·글 분당 175토큰으로 환산한 값이에요. 개발자 Gemini API 요금표에는 이 두 이름이 아직 안 보여서, 오늘 시험은 Platform 숫자를 참고하시면 돼요.
  • (장면) 블로그는 우편번호·주문번호처럼 숫자와 영어가 섞인 값을 시끄러운 소리 속에서도 받는다고 했어요. 맥 Gemini 앱에서는 받아쓴 글이 그림 만들기·파일 분석 같은 일을 다른 Gemini에게 넘겨 준다고 했고, Antigravity 마이크는 화면과 채팅 기록을 허락받은 뒤에만 붙여서 파일 이름·메모를 맞춘다고 적혀 있어요.
  • (영향) 인터뷰나 한 번에 찍은 영상을 자막으로 뽑는 팀은 오늘 gemini-3.5-transcribe로 짧은 클립만 돌려 보시면 돼요. 생방송 자막·목소리 비서는 실시간 쪽을, 회의록·통화 기록은 파일 쪽을 고르시면 되고, 말하는 사람이 네 명 넘으면 아직 시험 구간이라 사람이 한 번 더 보면 좋아요. 어제 나온 IBM Granite Speech 5.0(영어만, 파일을 받아 직접 돌리는 쪽)과 값·언어만 비교해 보시면 돼요.
