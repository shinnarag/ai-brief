Anthropic, Claude Opus 5 출시 — Fable급에 가깝고 가격은 Opus 그대로

  • 7/24(금) 공식: 두 달 안 Mythos 5·Fable 5·Sonnet 5에 이은 네 번째 플래그십. “Fable 5 프론티어 지능에 가깝고 가격은 절반” 포지션. Claude Max 기본 모델, Pro에서 최강 티어. API ID claude-opus-5.
  • 가격: 표준 $5 입력 / $25 출력 per 1M 토큰(Opus 4.8과 동일, Fable 입력가의 약 절반). Fast 모드 약 2.5× 속도·$10/$50. 요청당 low / medium / high(·max) effort 토글로 비용·능력 트레이드오프.
  • 벤치(공식): Frontier-Bench v0.1 max effort 43.3%(GPT-5.6 Sol 37.5%, Fable 5 33.7%, Opus 4.8 18.7%). CursorBench에서 Fable 피크 대비 0.5%p 안·동일 비용 대비 우위 주장. ARC-AGI 3·Zapier AutomationBench·OSWorld 2.0 등에서도 “동일 비용 대비 최고” 내러티브.
  • 제품 디테일: 기본·최대 100만 토큰 컨텍스트, max output 128k, thinking 기본 ON. 베타 — 대화 중 도구 변경(프롬프트 캐시 무효화 없이), 안전 분류기 차단 시 서버사이드 자동 폴백. Bedrock·Vertex·Microsoft Foundry 동시.
  • 안전: 행동 감사상 “최근 모델 중 가장 정렬”. 사이버·생물은 Mythos 5보다 뒤처짐 명시. 사이버 분류기는 Fable보다 덜 공격적(소스 취약점 탐색 허용, 바이너리 스캔·펜테스트·익스플로잇 생성 차단) — CVP 고객은 제한 완화 버전.
  • 개발·에이전트 팀은 Opus 4.8 라우트를 effort 정책으로 재설계하고, Fable 대비 단가·지연 A/B를 7일 내 돌릴 후보. 엔터프라이즈는 폴백·CVP 가입 여부를 RFP에 명시.
