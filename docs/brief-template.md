# AI Pulse 작성 템플릿

아래 코드 블록 안의 내용만 `briefs/AI-Daily-YYYY-MM-DD.md`로 복사합니다. 중괄호 자리표시자·날짜·예시 URL을 모두 실제 확인한 내용으로 바꿉니다. 이 템플릿 자체를 브리프로 저장하지 않습니다.

- 본문은 검증한 소식에 맞춰 카드를 추가합니다. 충분한 소식이 있는 날 약 8~12개이며, 아래 5개는 형식 예시입니다.
- 주요 카드는 출처 외 4~6개 불릿, 작은 소식은 1~2개 불릿을 씁니다. 내용 없는 카테고리를 채우려고 카드를 만들지 않습니다.
- Top 5의 순위는 편집 우선순위에 맞춰 정하고, 연결되는 본문 카드의 **제목을 그대로** 사용합니다. Top에는 한 줄 요약만 둡니다.
- `주제`와 본문은 해요체로 씁니다. 출처를 직접 읽고 신뢰도를 선택합니다. 본문에 쓴 출처를 참고 링크 표에 정리합니다.
- 헤더의 스윕 메모는 Markdown 원문에 남지만 화면에서 생략될 수 있습니다. 카드의 중요한 불확실성도 그 메모에만 적지 않습니다.
