   - Cloudflare가 11/5 Durable Objects의 fetch·RPC 요청에 자동 재시도를 추가했어요. 에이전트 상태나 작업을 보관하는 시스템의 일시적 전송 실패를 런타임에서 처리하는 변화예요.
   - 기본 최대 재시도는 4회이며 시작 뒤 10초가 지나면 새 재시도를 시작하지 않아요. Durable Object 코드 안의 오류나 overloaded로 표시된 실패까지 자동 해결하는 기능은 아니에요.
   - 요청 도착 여부가 불확실하면 다시 보내되 객체가 중복 요청의 실행을 막아요. 안전하게 반복할 수 있는 메서드만 retryable()로 표시해 재실행을 허용할 수 있어요.
   - 재시도 옵션과 retryable() 사용에는 Wrangler 4.158.0 이상이 필요해요. 기존 자체 재시도 반복문과 겹치면 시도 횟수가 늘 수 있으므로 중복 정책을 줄이거나 maxRetries를 0으로 설정하는 방법을 검토해야 해요.
   - 출처: [11/5 공식 변경 기록](https://developers.cloudflare.com/changelog/post/2026-11-05-durable-objects-automatic-retries/) · 신뢰도: 공식
