1. **Claude — Files API·Agent Skills 정식 공개, Admin 사용자 관리도 헤더 해제 (8/19)**
   - (사실) Anthropic이 8/19 플랫폼 릴리즈 노트에서 **Files API**와 **Agent Skills**(`/v1/skills`)를 정식으로 열었어요. `/v1/files`와 올린 파일을 가리키는 Messages 요청, `container`로 스킬을 불러오는 요청 모두 **베타 헤더가 더 이상 필요 없어요.** 예전 헤더를 보내도 그대로 받아 줘요.
   - (Files 범위) 파일 하나 **최대 500 MB**, 조직 저장 **1 TB**, 분당 약 **500 요청**이에요. 올릴 때 `expires_in_seconds`를 **1시간~90일**로 넣으면 `expires_at`이 생기고, 안 넣으면 `null`이에요. 워크스페이스 안의 모든 키가 같은 파일을 볼 수 있어서, 테넌트별로 워크스페이스를 나누셔야 해요. **ZDR 대상은 아니에요.**
   - (Skills) 미리 만든 스킬은 **PowerPoint(`pptx`)·Excel(`xlsx`)·Word(`docx`)·PDF(`pdf`)** 이고, 코드 실행 툴이 있어야 돌아가요. API 쪽 스킬 컨테이너는 **네트워크가 없고** 런타임에 패키지를 못 깔아요. claude.ai 커스텀 스킬은 개인 단위고, API는 워크스페이스 공유예요.
   - (같은 날) Enterprise **Admin API 사용자 관리**(멤버·초대·그룹·커스텀 롤)도 정식이에요. Managed Agents는 `web_search`/`web_fetch`에 **허용·차단 도메인**을 걸 수 있고, 셀프호스티드 샌드박스에 메모리 스토어를 붙일 수 있어요. 콘솔 세션 뷰어는 타임라인·요청별 트랜스크립트·비용 인스펙터로 바뀌었어요.
   - (영향) 브랜드 가이드 PDF와 레퍼런스 컷을 한 번 올려 두고 캠페인 초안에 재사용하시면 돼요. 슬라이드·시트 스킬은 스테이징에서 헤더를 뺀 요청으로 한 번만 확인해 보시면 좋아요.
   - 출처: [플랫폼 릴리즈 노트](https://platform.claude.com/docs/en/release-notes/overview) · [Files API](https://platform.claude.com/docs/en/build-with-claude/files) · [Agent Skills](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview) · 신뢰도: 공식

2. **Cursor — Cloud Agent 구독·커스텀 모드·서브에이전트 VM · `/goal` (8/19)**
   - (사실) Cursor가 8/19 changelog에서 클라우드 에이전트가 **이벤트에 반응해 일을 집어 가게** 만들었다고 밝혔어요. 어제 다룬 Origin(코드 호스팅 베타)과는 다른 업데이트예요.
   - (구독) 에이전트가 PR·Slack 스레드·스케줄 작업을 **구독**하고, 뭔가 생기면 깨어요. **지금은 클라우드 에이전트만**이에요. 자기가 만든 PR은 자동으로 구독해서 CI를 고치고 봇 코멘트까지 밀어 줘요. Slack에서는 `@cursor check back in an hour and keep going until that feedback is in`처럼 쓰라고 적혀 있어요.
   - (모드·VM) 아무 스킬이나 채팅에 고정하는 **Custom Mode**를 켤 수 있어요. `/`에서 스킬을 고른 뒤 Mac은 ⌥⏎, Windows는 Alt+Enter예요. 서브에이전트는 **각자 가상머신**에서 프로젝트 복사본을 받아, 부모 변경을 깨끗한 환경에서 테스트하거나 충돌 없이 고치게 했어요.
   - (`/goal`) 오래 가는 목표를 줄 수 있어요. 예시는 `/goal fix all flaky tests and make CI green`이고, 커스텀 모드나 `/loop`와 같이 쓰라고 해요. 작업 중에 보낸 팔로업은 에이전트를 끊지 않고 **다음 툴 콜까지 기다려요.**
   - (영향) 제작 툴 레포 CI를 클라우드 에이전트에 맡기는 팀은 PR 구독만 먼저 켜 보시면 돼요. Origin 호스팅과는 별개라서, 어제 붙여 본 미러 설정과 섞지 않으셔도 돼요.
